# AI-Powered Fraud Detection

A Java-based prototype for detecting potentially fraudulent financial transactions.

## Features

- Transaction amount analysis
- Unusual transaction time detection
- Failed login/transaction attempt detection
- New device detection
- New location detection
- Distance-based risk detection
- International transaction detection
- Fraud risk scoring
- LOW, MEDIUM and HIGH risk classification
- Recommended transaction action

## Technology

- Java
- Rule-based fraud detection
- VS Code

## How to Run

Compile:

javac FraudDetection.java

Run:

java FraudDetection

## Example

A transaction with a high amount, unusual time, multiple failed attempts, a new device, a new location and international activity can be classified as HIGH risk.

## Project Type

This is a prototype demonstrating the basic concept of AI-powered fraud detection using transaction risk factors and scoring.
